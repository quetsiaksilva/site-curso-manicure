Curso New Life

3 páginas interligadas: index.html (Home), sobre.html (Sobre), contato.html (Contato).
style.css é compartilhado pelas três páginas.

Foi utilizado o Bootstrap para deixar o site responsivo e melhorar a estrutura das páginas.

Recursos do Bootstrap utilizados:
- Navbar e menu responsivo
- Container
- Grid (row e col)
- Cards
- Botões
- Formulário
- Espaçamentos
- Imagens responsivas
- Bordas arredondadas
- Sombras

Também foram adicionados estilos personalizados no CSS para manter a aparência rosa e elegante da página original.

O site foi adaptado para funcionar em diferentes tamanhos de tela, como computadores, tablets e celulares.
